\begin{abstract}
\noindent
A class of LLM agent failure is invisible to single-axis memory
benchmarks: the verbal and action-emitting channels drift apart,
directives ceasing to reflect anchors the summaries continue to
mention. We name this \emph{stale coherence} and propose a
\emph{dual probe}---paired verbal and action-grounded recall---for
tick-continuous structured-output agent loops. We instantiate it
on a deterministic colony-simulation substrate that wires
\textsf{intent\_weights} / \textsf{target\_priorities} into worker
behaviour and resource flow, so action-grounded recall reflects
observable behaviour rather than a schema-local token echo. A
pilot across three model families at two horizons yields three
observations: dissociation crosses our pre-registered
$|\Delta| > 0.3$ threshold in four of eighteen cells; magnitude at
the 60-minute horizon orders by tier ($0.018 < 0.146 < 0.283$);
and direction reverses with horizon for non-frontier families. An
external LongMemEval-style needle-in-haystack probe on the same
models at matched context lengths recalls every recovered anchor
perfectly, so the dissociation is distinct from generic
long-context-recall failure. We frame the result as a
substrate-coupled pilot whose generalisation to non-colony agent
loops is an explicit open question, and release the substrate and
dual-probe toolkit as open source.
\end{abstract}
