\section{Introduction}
\label{sec:intro}

Large language models are increasingly deployed as hierarchical
decision-makers: a strategic planner emits high-level intents, a tactical
controller refines them into role-specific policies, and a per-entity
runtime grounds those policies into individual actions. This pattern is
canonical in production agent
systems~\citep{FAIR2022Cicero, AnthropicMultiAgent2025},
in robotics~\citep{Vinyals2019AlphaStar, Berner2019OpenAIFive}, and in
multi-agent collaboration frameworks~\citep{Hong2024MetaGPT,
Qian2024ChatDev, Vezhnevets2023Concordia}.

Yet existing LLM-agent benchmarks evaluate a substantially narrower
slice of this design space:

\begin{itemize}[leftmargin=*]
\item \textbf{Single-agent tool-use benchmarks}
(AgentBench~\citep{Liu2024AgentBench}, GAIA~\citep{Mialon2023GAIA},
WebArena~\citep{Zhou2024WebArena}, AgentBoard~\citep{Ma2024AgentBoard},
TheAgentCompany~\citep{Xu2025TheAgentCompany}) measure success on
episodic tasks with single-LLM dispatch and no parallel decision
channels.
\item \textbf{Flat MARL benchmarks}
(MeltingPot~\citep{Agapiou2022MeltingPot},
Crafter~\citep{Hafner2022Crafter}, BALROG~\citep{Paglieri2025BALROG})
test policies that emit primitive actions, with no natural-language
directive surface.
\item \textbf{Multi-agent LLM frameworks}
(ChatDev~\citep{Qian2024ChatDev}, MetaGPT~\citep{Hong2024MetaGPT},
AgentVerse~\citep{Chen2024AgentVerse}, X-MAS~\citep{Ma2025XMAS}) explore
agent collaboration but seldom combine \emph{cross-vendor heterogeneity}
with \emph{long-horizon} survival, structured \emph{schema-validated}
output, and \emph{deterministic substrate}.
\item \textbf{Long-context / memory benchmarks}
(LongMemEval~\citep{Wu2025LongMemEval}, RULER~\citep{Hsieh2024RULER},
MemoryArena~\citep{He2026MemoryArena}, MemoryAgentBench~\citep{Hu2026MemoryAgentBench})
probe verbal recall, but rarely couple recall failures to downstream
\emph{task} signal.
\end{itemize}

This gap matters because the most common production failure mode is
not "the LLM emitted an invalid action" --- schema validators
catch that --- it is \emph{coherent but stale} decisions: the
strategic-plan channel still references a long-evicted directive,
the npc-policy channel allocates resources to a problem solved an
hour earlier, the colony-agent channel commits to a build that
contradicts the environment-director's just-issued threat update.
Detecting this failure mode requires (a) parallel decision channels
running at distinct cadences, (b) a long horizon where directives
cumulate and decay naturally rather than being injected as synthetic
distractors, and (c) a deterministic substrate so that
hardware/timing variance does not mask reasoning failures.

\paragraph{Contributions.}
We introduce \textbf{Project-Utopia}, a deterministic
colony-simulation benchmark that closes this gap with four
contributions:

\begin{description}[leftmargin=*]
\item[C1 — Architectural.] A 4-channel LLM action surface
(environment-director, npc-policy, strategic-plan, colony-agent)
operating above an A* + Boids + seeded-RNG substrate. Schema validation
and numerical guardrails ensure \textbf{three-tier reproducibility}:
(i) bit-identical fallback mode (verified at 60, 1\,800, and 7\,200
ticks; hashes \texttt{e360b76\ldots}, \texttt{473d1b9\ldots},
\texttt{c2d86a6\ldots}), (ii) hardware-independent LLM-on mode via
LayerCast~\citep{Yuan2025LayerCast}, (iii) stationary
distribution production-LLM mode.

\item[C2 — Methodological.] A four-layer metric stack: (1) per-tick
dimension plugins emit raw signal; (2) a dimension normalizer applies
six transform types (identity, invert, reciprocal, clip-scale,
symmetric-rescale, exponential-decay) to project all 19 score keys
into $[0,1]$ benefit form; (3) MeltingPot-style sandwich
normalization~\citep{Agapiou2022MeltingPot} computes
$(\text{LLM} - \text{fallback})/(\text{oracle} - \text{fallback})$
on aligned per-seed paired runs; (4) Crafter geometric mean
composite~\citep{Hafner2022Crafter} for resource-allocation,
HELM Mean Win Rate~\citep{Liang2023HELM} for cross-model
leaderboards. Variance reduction follows
Pluribus AIVAT~\citep{Brown2019Pluribus}; statistical inference
follows~\citet{Bowyer2025DontUseClt}.

\item[C3 — Empirical.] Nine experiments yielding three findings:
(a) hierarchical decomposition advantage at matched token budget;
(b) \emph{cross-vendor channel-axis heterogeneous mix} achieves
near-strong-on-all RAE at $\sim$\,1/3 the cost --- going beyond
X-MAS~\citep{Ma2025XMAS} per-task routing and
Anthropic~\citep{AnthropicMultiAgent2025} intra-family mix;
(c) the first \emph{three-axis joint memory analysis}
($\text{Recall} \times \text{Drift} \times \text{Performance}$) on
continuous tick-level naturally-accumulated context, dissociating
verbal recall from action-grounded recall.

\item[C4 — Position-defining.] First benchmark in the 2025--2026
LLM-driven sim landscape combining (i) a deterministic 96$\times$72
tile economy, (ii) 4-channel parallel commands per tick, (iii)
FSM-worker emergent multi-resource economy, (iv) seeded year-scale
reproducibility, and (v) cross-vendor channel-axis heterogeneous
LLM mix evaluation. Each ingredient has prior art individually; the
5-way combination has none.
\end{description}

\paragraph{Relation to concurrent work.}
Three concurrent benchmarks deserve specific differentiation.
\textbf{Orak}~\citep{Krafton2026Orak} evaluates LLMs on 12 video
games via an MCP plug-and-play interface; we differ by going
\emph{depth-first} on a single deep simulator with 4-channel
parallel commands and dimension-decomposed scoring instead of
\emph{breadth-first} across shallow MCP shells.
\textbf{X-MAS}~\citep{Ma2025XMAS} demonstrates heterogeneous-LLM
benefits on per-task routing across 27 LLMs; we route \emph{per
channel within a single long-horizon survival task} and add
cross-vendor mixes that X-MAS does not test.
\textbf{MemoryArena}~\citep{He2026MemoryArena} probes
action-grounded recall in session-discrete agent loops; we run
on \emph{tick-continuous, naturally-accumulated} context and
report a three-axis decomposition that joint-analyzes recall
against drift and task performance.
