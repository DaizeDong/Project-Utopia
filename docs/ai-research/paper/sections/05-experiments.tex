\section{Experiments}
\label{sec:experiments}

We report three pre-registered experiments aligned with the two
hypotheses introduced in the abstract.
\textbf{E1} (Hierarchical Decomposition) directly tests \textbf{H1}:
orchestration $\Delta\text{RAE} \geq 0.10$ over a flat baseline at
matched token budget.
\textbf{E2} (Token Cost Decoupled from World Size) provides supporting
evidence that the 4-channel pipeline scales: per-decision token cost
remains roughly constant as entity count grows, so any orchestration
gain in E1 is not bought by inflating prompt size.
\textbf{E6} (Schema-Validated Failure Mode Profile) directly tests
\textbf{H2}: under 7\,200-tick coherence stress, schema rejection
rate per channel remains bounded with no compounding inter-channel
violation, and different LLM families exhibit distinct per-channel
failure profiles.

Additional analyses --- Decision-Token Efficiency (\S\ref{app:b1}) and
the post-hoc Bayesian vs.\ frequentist ranking comparison
(\S\ref{sec:metrics}) --- are reported alongside the main experiments
but are not used as evidence for H1 or H2. Three-tier reproducibility
verification is reported in \S\ref{sec:reproducibility}.

\subsection{Setup}
\label{sec:exp:setup}

\textbf{Scenarios.} We use four scenarios spanning two map templates
and two crisis injectors:
\textsc{S-Plains}, \textsc{S-Basin},
\textsc{S-Plains-Famine}, \textsc{S-Basin-Siege}.
\textbf{Seeds.} Main experiments use ten seeds drawn from a fixed list
($\{0\text{xC0FFEE}, \ldots\}$).
\textbf{Models.} Single Claude-Sonnet model for H1 (E1, E2); for H2
(E6), three model families to surface per-channel failure profiles
(one frontier closed-weight, one mid-tier closed-weight, one
open-weight 7B-tier) plus the no-LLM fallback baseline.
\textbf{Run length.} 7\,200 ticks (240 sim-seconds) for all reported
experiments.
\textbf{Token budget.} Per-decision token budget is matched across
the hierarchical and flat-baseline arms of E1; both arms route every
directive through \texttt{Guardrails} so the agent--tool contract is
held constant across architectures.

\subsection{E1 --- Hierarchical Decomposition is Necessary}
\label{sec:exp:e1}

\paragraph{Hypothesis (H1).} Under matched per-decision token budget,
the 4-channel tool-orchestration contract achieves at least
$\Delta \text{RAE} = 0.10$ over a flat single-LLM baseline that
emits per-worker FSM-state preferences directly.

\paragraph{Design.} 2 architectures (\texttt{hierarchical},
\texttt{flat-baseline}) $\times$ 2 scenarios
(\textsc{S-Plains}, \textsc{S-Basin}) $\times$ 10 seeds
$\times$ 1 model (Claude-Sonnet) $=$ 40 runs.
Token budget capped at 200\,k tokens per run; both arms run through
\texttt{Guardrails} so schema validity is matched. The flat baseline
(\texttt{FlatBaselineAdapter}) collapses all four channels into a
single prompt that emits per-worker FSM-state preferences directly,
without the intermediate environment / strategic / policy abstraction.

\paragraph{Expected results.} Following the calibration anchor of
ChatDev's $-44\%$ role-removal effect~\citep{Qian2024ChatDev}, we
expect hierarchical RAE $\sim$\,0.65--0.75 vs.\ flat
$\sim$\,0.30--0.55, depending on scenario; the H1 threshold of
$\Delta\text{RAE} = 0.10$ is the minimum effect we treat as
confirmatory.

\paragraph{Status.} Pipeline verified end-to-end via
\texttt{project-utopia run --experiment E1} (smoke run
produced 19 NDJSON rows / $\sim$3\,s on FB cell). Full E1 runs pending a one-week
dedicated GPU window. Figure~\ref{fig:e1} previews the bar-chart
layout populated from the fallback-only smoke run.

\subsection{E2 --- Token Cost is Decoupled from World Size}
\label{sec:exp:e2}

\paragraph{Hypothesis.} Pearson correlation between
\texttt{prompt\_tokens / decision} and entity count is
$\rho < 0.20$ --- i.e., the \texttt{pickHighlights}-truncated
PromptPayload effectively decouples token cost from world load.
This supports the H1 claim by ruling out the trivial alternative
that the 4-channel architecture beats the flat baseline simply by
consuming more prompt tokens as the world grows. A complementary
decision-token efficiency analysis is reported in \S\ref{app:b1}.

\paragraph{Design.} World size $\in \{4, 8, 16, 24, 36\}$ initial
workers $\times$ 5 seeds $\times$ 1 scenario (\textsc{S-Plains})
$=$ 25 runs.

\paragraph{Expected result.} Slope of
$\text{tokens/decision} \sim a + b \cdot \text{entityCount}$
with $|b| / a < 0.10$ across all four channels (Figure~\ref{fig:e2}).

\subsection{E6 --- Schema-Validated Failure Mode Profile}
\label{sec:exp:e6}

\paragraph{Hypothesis (H2).} Under 7\,200-tick coherence stress,
schema rejection rate per channel remains bounded
($\leq 5\%$ for frontier models, $\leq 25\%$ for the 7B-tier
open-weight model) with no compounding inter-channel violation
(joint reject rate $\leq$ product of per-channel rates, within a
factor of 1.5). Different LLM families exhibit distinct per-channel
failure profiles --- the 7B-tier open-weight model exhibits at least
$5\times$ higher schema reject rate than the frontier closed-weight
model on the JSON-heavy \emph{strategic-plan} channel.

\paragraph{Design.} 3 models $\times$ 2 scenarios $\times$ 5 seeds
$\times$ 7\,200 ticks $=$ 30 runs. Per-channel schema-rejection
rates are emitted as side-channel telemetry on
\texttt{state.metrics.aiRuntime.schemaErrors}, broken out by
channel (\emph{environment-director}, \emph{npc-policy},
\emph{strategic-plan}, \emph{colony-agent}) and by failure category
(\{schema reject, timeout, parse fail, fallback occupancy\}).

\paragraph{Expected results.} Figure~\ref{fig:e6} reports the
cell $\times$ failure-mode heatmap. The per-channel schema-reject
rate is bounded; the predicted $5\times$ gap between open-weight and
frontier rows on the \emph{strategic-plan} channel is visible. A
numeric companion table accompanies the camera-ready version once
the full 3-model sweep lands.
