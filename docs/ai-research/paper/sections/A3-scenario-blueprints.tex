\subsection{Oracle Validation}

For each oracle, the test
\texttt{benchmark-oracle-policy-idempotent.test.js} verifies that:
(a) \texttt{validateEnvironmentDirective} / \texttt{validateGroupPolicy}
succeed without modifying any field;
(b) \texttt{guardEnvironmentDirective} / \texttt{guardGroupPolicies}
return a deep-equal copy of the input (no clamping has any effect);
(c) calling guard twice produces the same result as calling once
(idempotent fixed point).
This ensures that "oracle" is a meaningful upper bound for the
sandwich-norm: the scripted policy operates exactly within the
schema's allowed values, neither under nor over.
