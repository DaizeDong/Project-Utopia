\begin{abstract}

Existing LLM-agent benchmarks evaluate single agents picking single
tools~\citep{Liu2024AgentBench, Mialon2023GAIA, Zhou2024WebArena,
Schick2023Toolformer, Patil2023Gorilla, Qin2024ToolLLM} or flat MARL
policies emitting primitive actions in stateless
games~\citep{Agapiou2022MeltingPot, Hafner2022Crafter,
Paglieri2025BALROG}, leaving the regime where an LLM agent
\textbf{orchestrates a fixed, schema-validated tool surface across
multiple parallel decision channels} largely under-evaluated --- despite
this being the canonical pattern in production agent systems
\citep{FAIR2022Cicero, Vinyals2019AlphaStar, AnthropicMultiAgent2025,
Shen2023HuggingGPT}.
We introduce \textbf{Project-Utopia}, a tool-grounded benchmark
exposing four hierarchical LLM decision channels
(\emph{environment-director}, \emph{npc-policy}, \emph{strategic-plan},
\emph{colony-agent}) that orchestrate a deterministic,
schema-validated tool surface (path queries over a versioned grid,
group steering, FSM intent application, build planning).
Schema validation and numerical guardrails ensure \textbf{three-tier
reproducibility}: (i) bit-identical fallback mode (verified at 7\,200
ticks), (ii) hardware-independent LLM-on mode via
LayerCast~\citep{Yuan2025LayerCast}, (iii) statistically stationary
production-LLM mode.

We propose a four-layer metric stack combining per-tick dimension
plugins (Resource-Allocation Efficiency, Group Dynamics, Memory
Degradation, Decision Token Efficiency, Hierarchical Coordination)
with MeltingPot-style sandwich
normalization~\citep{Agapiou2022MeltingPot}, Crafter geometric
mean~\citep{Hafner2022Crafter}, HELM Mean Win Rate~\citep{Liang2023HELM},
and Pluribus-style PolicyValue Baseline~\citep{Brown2019Pluribus} for
$\sim$\,2--3$\times$ seed-variance reduction. Statistical inference
follows~\citet{Bowyer2025DontUseClt}'s ICML 2025 Spotlight
recommendation of Beta-Binomial credible intervals for small-$N$.

We design a nine-experiment matrix (E1--E9) over seven LLM families,
five scenarios, ten seeds (\(\sim\)\,2\,250 runs total) targeting three
empirical findings: \textbf{(i)} hierarchical decomposition outperforming
a matched-budget flat baseline by \(\sim\)\,0.10 RAE (calibrated against
ChatDev's \(-44\%\) role-removal effect size~\citep{Qian2024ChatDev});
\textbf{(ii)} cross-vendor channel-axis heterogeneous LLM mixes
(Anthropic + OpenAI + open-weight) approaching strong-on-all RAE at
\(\sim\)\,1/3 the cost --- going beyond X-MAS~\citep{Ma2025XMAS}'s
per-task routing and Anthropic's intra-family
mix~\citep{AnthropicMultiAgent2025}; \textbf{(iii)} the first
\textbf{three-axis joint memory analysis}
(\(\text{Recall}(t) \times \text{Drift}(t) \times \text{Performance}(t)\))
on continuous tick-level naturally-accumulated context, designed to
dissociate verbal recall from action-grounded recall in ways
LongMemEval~\citep{Wu2025LongMemEval} and
MemoryArena~\citep{He2026MemoryArena} cannot.
At submission, the pipeline is end-to-end verified on fallback-only
NDJSON; the five \S\ref{sec:experiments} figures show structural
layout, with cell-level signal populated for the camera-ready from
real-LLM runs once API access is provisioned.

Project-Utopia is released as a self-contained Python package
(\texttt{pip install project-utopia}, 615 tests passing,
$\sim$\,23\,k LOC, 128 modules) with one-line CLI reproducibility, a
record-replay LLM cache via pydantic schemas, and full
JSON-NDJSON paper-run pipeline. Code, prompts, and 7\,200-tick
determinism manifests are at

\end{abstract}
