\begin{abstract}

A production-deployed LLM agent rarely fails by forgetting an anchor
outright. It fails by a more subtle failure mode: it continues to
\emph{mention} the anchor in its summaries while its directives stop
\emph{acting} on it. We call this failure mode \textbf{stale
coherence} and argue that it is an independent axis of LLM behavior
distinct from raw recall as measured by LongMemEval~\citep{Wu2025LongMemEval},
RULER~\citep{Hsieh2024RULER}, Lost-in-the-Middle~\citep{Liu2024LostInMiddle},
or MemoryArena~\citep{He2026MemoryArena}.

We define stale coherence operationally as the dual probe
$\bigl(\,\text{verbal\_recall}(t),\,\text{action\_grounded\_recall}(t)\,\bigr)$
and the dissociation metric
$\Delta(t) = \text{verbal\_recall}(t) - \text{action\_grounded\_recall}(t)$.
A single anchor is injected at $t = 0$ carrying both verbal tokens
(``warehouse at $(12,8)$'') and an implicit action goal
(\texttt{\{deliver, warehouse\}}). At every sample point $t > 0$, the
\emph{verbal} probe checks whether the LLM-emitted summary still
mentions the anchor; the \emph{action-grounded} probe checks whether
the LLM's structured directives still allocate non-trivial weight to
the anchor's implicit goal. Stale coherence is the regime where these
two probes diverge.

To make stale coherence measurable, we build Project-Utopia, a
deterministic 8-sim-hour colony-simulation harness in which a single
LLM emits structured directives across four parallel channels
(\emph{environment-director}, \emph{npc-policy}, \emph{strategic-plan},
\emph{colony-agent}) at three nested cadences. The multi-cadence
structured-output substrate is what makes the dissociation visible:
single-cadence benchmarks cannot dissociate verbal mention from
sustained behavioral commitment. Schema validation and idempotent
guardrails ensure that what we measure is reasoning drift, not
parse error or hardware non-determinism (three-tier reproducibility
with bit-identical fallback hashes \texttt{be19781c\ldots} verified at
seed \texttt{0xC0FFEE}).

We evaluate a single pre-registered hypothesis: \textbf{H}: for every
LLM family $m$ in our model menu, there exists
$t^{\star}(m) \leq 4\,\text{sim-hours}$ such that
$\Delta(t^{\star}) > 0.3$. We additionally test whether stale
coherence is statistically independent of LongMemEval-style verbal
recall: if the dissociation gap correlates strongly with raw recall,
the phenomenon reduces to known long-context bias; if it does not,
stale coherence is a new axis production agent designers must
explicitly test for.

At submission time, the pipeline is verified end-to-end on
fallback-only NDJSON. Real-LLM evaluation across Claude-Sonnet-4.6,
GPT-5-mini, and Llama-3.1-8B is reserved for the camera-ready once
API access is provisioned. Project-Utopia is released as a Python
package (\texttt{pip install project-utopia}, 615 tests passing,
$\sim$\,23\,k LOC, 128 modules) at [ANONYMIZED-REPO-URL]
(de-anonymized for camera-ready).

\end{abstract}
